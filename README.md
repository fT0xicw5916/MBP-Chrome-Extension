# MBP-Chrome-Extension
Just a simple, minimal Chrome extension built around ManageBac that adds a lot of useful functions to it.

## Table of contents
* [Features](#features)
* [Usage](#usage)
* [Privacy Policy](PRIVACY.md)

## Features
- GPA calculator for mid-terms and finals
- We're being minimalist so... not a lot of features yet!

## Usage
Just [download](https://chromewebstore.google.com/detail/ogcohddcbfgnlhifdkgjkpfdnimmbngl?utm_source=item-share-cb) from the Chrome Web Store and start using it immediately!

Open the "Tasks & Units" page for any subject on ManageBac and starting simulating your GPAs!
